# 1. NumPy
Uso: Cálculos numéricos e manipulação de arrays/matrizes.

Exemplo: Operações matemáticas eficientes em grandes conjuntos de dados.
# 2. Pandas
Uso: Manipulação e análise de dados.

Exemplo: Trabalhar com tabelas (DataFrames), limpar e analisar grandes volumes de dados.
# 3. Matplotlib
Uso: Criação de gráficos e visualizações.

Exemplo: Gerar gráficos de barras, linhas, dispersão e outros tipos de visualizações.
# 4. Seaborn
Uso: Visualização de dados estatísticos.

Exemplo: Extensão do Matplotlib, facilita a criação de gráficos complexos e atraentes.
# 5. Scikit-learn
Uso: Machine Learning (ML).

Exemplo: Algoritmos de aprendizado supervisionado e não supervisionado (classificação, regressão, agrupamento).
# 6. TensorFlow
Uso: Deep learning e inteligência artificial.

Exemplo: Desenvolvimento de redes neurais para tarefas como reconhecimento de imagem, NLP, etc.
