# 1. NumPy
Uso: Cálculos numéricos e manipulação de arrays/matrizes.

Exemplo: Operações matemáticas eficientes em grandes conjuntos de dados.
# 2. Pandas
Uso: Manipulação e análise de dados.

Exemplo: Trabalhar com tabelas (DataFrames), limpar e analisar grandes volumes de dados.
# 3. Matplotlib
Uso: Criação de gráficos e visualizações.

Exemplo: Gerar gráficos de barras, linhas, dispersão e outros tipos de visualizações.
# 4. Seaborn
Uso: Visualização de dados estatísticos.

Exemplo: Extensão do Matplotlib, facilita a criação de gráficos complexos e atraentes.
# 5. Scikit-learn
Uso: Machine Learning (ML).

Exemplo: Algoritmos de aprendizado supervisionado e não supervisionado (classificação, regressão, agrupamento).
# 6. TensorFlow
Uso: Deep learning e inteligência artificial.

Exemplo: Desenvolvimento de redes neurais para tarefas como reconhecimento de imagem, NLP, etc.

# 7. Keras
Uso: Interface de alto nível para o TensorFlow.

Exemplo: Criação e treinamento de modelos de deep learning de forma simplificada.
# 8. Flask
Uso: Desenvolvimento de aplicativos web (microframework).

Exemplo: Criar aplicações web simples e APIs.
# 9. Django
Uso: Desenvolvimento de aplicativos web (framework completo).

Exemplo: Criação de sites e sistemas web robustos e escaláveis.
# 10. Requests
Uso: Envio de requisições HTTP de forma simples.

Exemplo: Consumo de APIs e interação com serviços web.
# 11. BeautifulSoup
Uso: Parsing e extração de dados de páginas HTML e XML.

Exemplo: Web scraping para coleta de dados da web.
# 12. SQLAlchemy
Uso: ORM (Object-Relational Mapping) para interagir com bancos de dados SQL.

Exemplo: Trabalhar com bancos de dados de maneira orientada a objetos.
# 13. Pillow
Uso: Processamento de imagens.

Exemplo: Abrir, manipular e salvar imagens em diversos formatos.
#14. Pytest
Uso: Testes automatizados.

Exemplo: Criar testes para garantir que o código funcione corretamente.
# 15. OpenCV
Uso: Processamento e análise de imagens e vídeos.

Exemplo: Reconhecimento facial, detecção de objetos, etc.
# 16. SymPy
Uso: Matemática simbólica.

Exemplo: Simplificação de expressões matemáticas e cálculo simbólico.
# 17. PyGame
Uso: Desenvolvimento de jogos.

Exemplo: Criar jogos 2D e interações multimídia.
# 18. Scrapy
Uso: Framework para web scraping.
Exemplo: Extrair grandes volumes de dados da web de forma eficiente.
# 19. Celery
Uso: Filas de tarefas assíncronas e agendamento de tarefas.
Exemplo: Gerenciamento de tarefas distribuídas, como envio de e-mails em segundo plano.
# 20. NLTK
Uso: Processamento de linguagem natural.
Exemplo: Análise de texto, tokenização, stemming e outras tarefas de NLP.
